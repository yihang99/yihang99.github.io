# Yihang Hu Personal Homepage

Static academic homepage for `yihang99.github.io`.

## Local Preview

Open `index.html` directly in a browser, or run a tiny static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Update Content

- Edit `index.html` to update bio, publications, links, email, and CV.
- Replace `assets/avatar.jpg` if you want a different portrait.
- Edit `styles.css` for visual changes.

## Deploy With GitHub Pages

Commit these files and push them to the `master` branch of the `yihang99.github.io` repository. GitHub Pages will serve the site at `https://yihang99.github.io/`.
